## Original request

**29 images total.** Make them in the same glossy cartoon style as your Sig Fig Sleuth set: transparent background, no text except the numbers or symbols listed. Drop each file into `assets/` (mascots into `assets/mascot/`) with the exact name below. The game picks each one up automatically; until a file exists it keeps showing today's icon.

Charts, tables, glassware and equation boxes are drawn by the game's code. Don't make those.
